# Цветная сетка Mangle

Пользователь согласовал две колонки и цвета текущего состояния правил.

- Правила выводятся слева направо по два, в исходном порядке; при нечётном
  количестве последняя строка содержит одну кнопку.
- Включённое правило: `style=success`, выключенное: `style=danger`.
  Цвет отражает состояние до нажатия, не предлагаемое действие.
- Значки ✅/❌ и названия сохраняются. Произвольные цвета не используются.
- «Обновить» и «Назад» в Mangle control/status используют `style=primary`
  и остаются отдельными строками после правил.
- Пустой список содержит только навигацию. Подтверждение/отмена сохраняют
  существующий вид; callbacks, токены, авторизация и RouterOS не меняются.
- `/mangle` и пункт управления Mangle используют общий builder.
- Telegram transport уже сериализует reply_markup целиком, поэтому `style`
  передаётся без изменения транспортного кода.

Источник полей API: https://core.telegram.org/bots/api#inlinekeyboardbutton.
Проверки: пустой, одиночный, чётный и нечётный списки; порядок/токены;
цвета обоих состояний; навигация; полная регрессия Telegram handlers.
Deploy на SELKS выполняется отдельно после согласования.
